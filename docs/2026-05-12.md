# 인스타 인플루언서 데이터 분석 결과물 

📊 인스타그램 인플루언서 광고 효율 분석 (2024)
1. 분석 개요
목적: 인플루언서의 팔로워 규모와 실제 참여율(recent_60_day_eng_rate_pct) 간의 관계를 분석하여 최적의 광고 집행 대상 발굴
데이터: 글로벌 상위 200명 인플루언서 성적표
핵심 지표: 최근 60일간의 참여율 (Engagement Rate)
2. 🔍 핵심 인사이트 (Key Insights)
❶ "메가"라고 다 똑같은 효율이 아니다 (효율의 극과 극)
팔로워 1위인 **Cristiano(4.7억 명)**의 최근 참여율은 **1.39%**인 반면,
**Lisa(lalalalisa_m)**는 팔로워가 상대적으로 적음에도 참여율 **9.0%**를 기록했습니다.
👉 인사이트: 팔로워 수만 보고 광고를 맡기면 효율이 6배 이상 차이 날 수 있습니다.
❷ 마이크로 세그먼트의 승리 (참여율 상위 10%의 특징)
참여율이 5%를 상회하는 인물들은 주로 Billie Eilish(5.02%), Zendaya(3.17%) 등 팬덤 결집력이 강한 아티스트 그룹에 집중되어 있습니다.
👉 인사이트: 단순 대중성보다 '강력한 팬덤'을 보유한 인플루언서가 광고 노출 대비 실제 반응(좋아요/댓글)을 이끌어내는 데 훨씬 유리합니다.
❸ 팔로워 규모와 참여율의 역상관 관계
분석 결과, 팔로워가 가장 많은 그룹(Q4 팔로워 높음)의 평균 참여율보다, 상대적으로 적은 그룹의 반응 밀도가 더 높게 나타나는 패턴이 확인됩니다. (일반적으로 팔로워가 늘어날수록 유령 계정 및 비활동 유저 비율이 늘어나기 때문)
3. 💡 비즈니스 전략 제안 (Action Items)
'효율 중심' 타겟팅: 단순히 랭킹 1위(호날두)를 고집하기보다, 참여율이 5% 이상인 **리사(Lisa)**나 **빌리 아일리시(Billie Eilish)**와 같은 고효율 인플루언서를 1순위 광고 파트너로 고려해야 합니다.
가성비 믹스 전략: 메가 인플루언서 1명에게 예산을 몰빵하기보다, 참여율이 검증된 '참여율 상위 10%' 그룹 내 인플루언서 3~4명에게 분산 투자하는 것이 총 도달 반응(Total Engagement) 면에서 유리합니다.
4. 📈 데이터 분석 포인트 (Tech Stack)
Language: Python
Library: Pandas (Data Cleaning), Seaborn (Visualization)
Process: 구글 드라이브 연동 -> 결측치 제거 -> 참여율 기반 랭킹 분석 -> 규모별 가성비 비교
